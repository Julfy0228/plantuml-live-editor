# Проверка релиза 1.0

Среда: Windows 11 x64, OpenJDK 17.0.18, Apache Maven 3.9.12.

Maven package: BUILD SUCCESS. Полный набор: 28 тестов, 0 ошибок, 0 пропусков. Дополнительно 9 проверок локализации, перерисовки и выбора формата прошли с системной локалью en-US.

Проверено:
- PNG/SVG для sequence, class, component, activity и JSON; обычный Graphviz и принудительная Smetana.
- Номер строки ошибки, отсутствие PNG/SVG для невалидного кода, последующий рендер после изменения исходника.
- Фон очищается при смене изображения, масштаба, снятии индикатора предыдущей версии и очистке просмотра.
- Вписывание большой диаграммы и возврат прокрутки в начало.
- Русский/английский наборы переводов, определение системного языка, локализованные стандартные файловые диалоги.
- Один диалог экспорта: PNG/SVG, синхронизация расширения, отсутствие двойных расширений.
- Начальный документ и «Новый» используют минимальный пример Alice -> Bob : hello.
- UTF-8, кириллица, сохранение/замена файлов и сохранение исходного текста без удаления Markdown-ограждений.
- Подсветка PlantUML и объединение фоновых заданий без показа устаревших результатов.
- Неожиданная ошибка рендера не останавливает обработку последующих изменений.

На фрагментах с лишней закрывающей скобкой воспроизведён внутренний IllegalStateException PlantUML 1.2026.9. Библиотека может печатать этот стек в консоль. Приложение не исправляет код, показывает ошибку, не экспортирует невалидный результат и ждёт изменения исходника. Исходный пользовательский случай без кода диаграммы точно воспроизвести невозможно.

Взаимодействие с видимым окном и системным буфером вручную в этой сессии не проверялось. Проверки отрисовки и файловых диалогов выполнены автоматически в headless-режиме. Для Linux/macOS нужен отдельный прогон GUI.

Программа не создаёт сохраняемых настроек и не изменяет ассоциации файлов Windows. Сетевые настройки Maven пользователя также не изменены; для сборки использован отдельный рабочий Maven-кэш.
