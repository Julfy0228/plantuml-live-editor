# License files

This directory preserves license texts and notices for the third-party software used by the project.

See [THIRD-PARTY.md](../THIRD-PARTY.md) for the component inventory, license mapping, and exact source download links. See [LICENSE](../LICENSE) for the editor's GPL-3.0 license.

The nested `META-INF` paths mirror original upstream archives. In particular, PlantUML's `META-INF/LICENSE` and `COPYING` belong to embedded JLaTeXMath components; they are not a substitute for PlantUML's own GPL-3.0 license, supplied separately as `plantuml/UPSTREAM-GPL-3.0.txt`.

`plantuml/SOURCE-NOTICES.txt` is a deduplicated, verbatim collection of original source-file notice blocks from `plantuml-1.2026.9-sources.jar`, with source paths retained. `graphviz/LICENSE.txt` is extracted from the native Graphviz archive inside PlantUML, rather than inferred from the Java wrapper's license.
