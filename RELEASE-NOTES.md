# PlantUML Live Editor 1.0.1

- Квадратные кнопки инструментов и единая высота кнопок.
- Управление диаграммой в одну строку; в узком окне подписи экспорта сворачиваются до значков с подсказками.
- Поиск рядом с файловыми действиями; имя файла остаётся в заголовке окна.
- Более мягкий фон номеров строк, различимые дорожка и бегунок прокрутки.
- Понятные статусы источника и времени отрисовки.
- Общее число совпадений при поиске и правильные русские окончания.

Проверка: 31 тест, 0 ошибок.

Java 17+. Запуск: `java -jar plantuml-live-editor.jar`.
В assets прикреплён только JAR; исходники и лицензии доступны в репозитории этого тега.
