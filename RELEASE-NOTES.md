# PlantUML Live Editor 1.0

Первый публичный релиз.

- Один переносимый JAR для Java 17+.
- Тёмный редактор PlantUML с номерами строк, подсветкой, поиском и заменой.
- Live preview с debounce и фоновым рендером.
- Копирование картинки и сохранение PNG/SVG через единый диалог.
- Открытие/сохранение .puml, масштабирование и вписывание.
- Автоматический русский/английский интерфейс по системной локали.
- Ошибки показываются без автоматического исправления исходника.
- Лицензии и уведомления зависимостей включены в репозиторий и внутрь JAR.

Запуск: `java -jar plantuml-live-editor.jar`.

Исходники редактора: дерево этого тега. Лицензии и точные ссылки на исходники зависимостей: `LICENSE`, `THIRD-PARTY.md`, `licenses/` в дереве тега `v1.0`.

Вручную прикреплённый asset релиза — только `plantuml-live-editor.jar`.
